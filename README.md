# Sitemap XML to HTML Generator
✨ PHP 全自动生成 **SEO优化 + AI GEO地理收录** 标准的HTML站点地图

## 项目简介
一款轻量级PHP脚本，自动读取网站根目录的 `sitemap.xml`，一键生成符合搜索引擎爬虫、AI大模型收录规则的静态HTML站点地图，零配置、开箱即用。

## 核心特性
- 🚀 自动解析标准Sitemap 0.9协议
- 🔍 符合SEO搜索引擎优化规范
- 🌍 支持AI GEO地理坐标收录
- 📝 自动生成静态 sitemap.html 文件
- 📱 响应式布局，适配全设备
- 🛡️ 安全防护，XSS过滤、XML错误捕获
- 🎯 兼容PHP 5.6 ~ 8.4 所有版本

## 快速使用
1. 将 `sitemap.php` 上传至网站**根目录**（与 sitemap.xml 同目录）
2. 浏览器访问：`https://你的域名/sitemap.php`
3. 自动生成并输出页面 + 静态 sitemap.html

## SEO + AI GEO 优化标准
### 搜索引擎优化
- 语义化HTML5结构
- Meta标签/Canonical/Robots 规范
- Schema.org 结构化数据
- 纯文本链接，100%抓取友好

### AI GEO 地理收录
- 地理Meta标签（geo.region/geo.placename）
- 支持经纬度解析展示
- 适配AI大模型、本地搜索收录
